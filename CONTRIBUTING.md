# Contribuir al proyecto

## Flujo recomendado
1. Crear rama desde `main`.
2. Hacer cambios pequeños y atómicos.
3. Añadir/actualizar documentación y pruebas.
4. Abrir PR con descripción clara.

## Convenciones
- Commits descriptivos (ejemplo: `feat(supabase): add learning_tasks table`).
- No incluir secretos en commits.
- Mantener cambios acotados por PR.

## Checklist mínimo para PR
- [ ] Código y docs actualizados.
- [ ] Tests relevantes pasan en local.
- [ ] No se exponen credenciales.
- [ ] Se explica impacto técnico y funcional.

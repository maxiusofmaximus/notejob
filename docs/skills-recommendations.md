# Skills recomendadas para NoteJob (skills.sh)

Consulta realizada en `https://skills.sh` con Playwright.

## Skills sugeridas
1. `webapp-testing`  
Fuente: `anthropics/skills/webapp-testing`  
Uso recomendado: pruebas E2E/regresión de flujos clave (`/app`, `/admin`, `/docs`, auth, vault, settings).

2. `audit-website`  
Fuente: `squirrelscan/skills/audit-website`  
Uso recomendado: auditoría de calidad de UX, contenido y consistencia de navegación.

3. `better-auth-best-practices`  
Fuente: `better-auth/skills/better-auth-best-practices`  
Uso recomendado: reforzar decisiones de autenticación y sesión admin/user.

4. `frontend-design`  
Fuente: `anthropics/skills/frontend-design`  
Uso recomendado: revisiones visuales periódicas (tipografía, ritmo visual, microinteracciones, responsive).

## Prioridad recomendada
1. `webapp-testing`
2. `better-auth-best-practices`
3. `audit-website`
4. `frontend-design` (ya en uso en este proyecto)

## Criterio de adopción
- Instalar skill si añade una capacidad que no tenemos localmente.
- Mantener skills con impacto directo en calidad de entrega (seguridad + testing + UX).
